# Этап 8: схема данных учеников и расчёт уровней (согласовано 2026-10-26)

Решения: DECISIONS.md №42–45, №57–65.

## Где лежат данные

Отдельная схема базы `school` (№45). На таблицы вопросов (`public`) данные учеников ссылаются только через id:
`question_id`, `topic_id`, `subject_id` хранятся как обычные uuid, без внешних ключей. Так схему `school` можно целиком
перенести на казахстанский хостинг, если этого потребует юрист.

## Таблицы

| Таблица | Что хранит | Главные поля |
|---|---|---|
| `school.students` | ученик | `id` (= аккаунт входа), `nickname` (уникальный, для входа), `display_name` («Айгерим С.»), `created_at` |
| `school.classes` | класс учителя по одному предмету (№63) | `id`, `teacher_id`, `subject_id`, `grade`, `school_name`, `letter`, `join_code` (6 символов, уникальный), `copied_from` (класс, чьих учеников взяли), `created_at` |
| `school.class_members` | кто в каком классе | `class_id`, `student_id`, `joined_at`; один ученик — в нескольких классах |
| `school.test_runs` | один пройденный тест | `id`, `student_id`, `subject_id`, `grade`, `topic_id` (пусто — смешанный тест), `assignment_id` (пусто — свободный тест), `score`, `total`, `finished_at` |
| `school.answers` | один ответ на вопрос | `id`, `run_id`, `student_id`, `question_id`, `topic_id`, `subject_id`, `option_id`, `is_correct`, `answered_at` |
| `school.assignments` | задание учителя | `id`, `class_id`, `title`, `kind` (обычное / пробное ЕНТ), `mode` (тренировка / контрольная, №20), `question_count`, `due_at`, `retries` |
| `school.assignment_items` | из чего собрано задание | `assignment_id`, `topic_id` или `question_id` |
| `school.settings` | пороги и сроки | `level_good` = 80, `level_partial` = 50, `level_min_answers` = 5, `level_window` = 20, `inactive_days` = 7 |

Вход ученика: Supabase Auth с адресом `ник@students.bilimtest.local` вместо email. Ученик видит только поле «ник».
Письма такой адрес не получает, пароль сбрасывает учитель (№43).

## Как записываются результаты

- Ученик не вошёл: всё как сейчас, ничего на сервер не пишется, кроме общей анонимной статистики (`public.attempts`).
- Ученик вошёл: в конце любого теста браузер отправляет функции `school.submit_run` **выбранные варианты**, а не «верно/неверно».
  Правильность считает база по таблице `options`, поэтому подделать результат нельзя.
- Пишется один `test_run` и по строке `answers` на каждый вопрос.

## Как считается уровень по теме

Для ученика и темы берутся его **последние 20 ответов** по этой теме (`level_window`), процент = верные / все × 100.

| Ответов по теме | Процент | Уровень |
|---|---|---|
| меньше 5 (`level_min_answers`) | любой | «мало данных» (серый) |
| 5 и больше | 80 и выше (`level_good`) | «знает хорошо» (зелёный) |
| 5 и больше | от 50 (`level_partial`) до 79 | «частично» (жёлтый) |
| 5 и больше | меньше 50 | «не знает» (красный) |

Почему последние 20, а не все ответы: если ученик подтянул тему, уровень это покажет. При подсчёте по всем ответам старые ошибки
держали бы его в «не знает» месяцами. Все пороги меняются в `school.settings` без переделки кода.

## Что видит учитель

**По ученику:**
- число пройденных тестов и средний процент (по `test_runs` предмета класса);
- уровень по каждой теме (таблица выше);
- темы и тесты не своего класса помечены «тема N класса» (№64);
- вопросы с ошибками: где последний ответ неверный, сверху — где ошибок больше всего;
- прогресс по неделям: число тестов и средний процент за каждую неделю (по времени Алматы, неделя с понедельника).

**По классу:**
- таблица «ученики × темы», в клетках — цвет уровня;
- топ-5 трудных тем: процент верных ответов всего класса по теме за последние 30 дней, считаются только темы, где хотя бы
  3 ученика дали по 5 и больше ответов;
- кто не занимался больше 7 дней (`inactive_days`): последний `test_run` старше 7 дней или его нет;
- выгрузка в Excel: лист «Ученики» (тесты, средний процент, дата последнего теста) и лист «Темы» (таблица уровней).

## Что видит ученик

- свои уровни по темам каждого предмета;
- кнопка «Повторить слабые темы»: тест из 10 вопросов из тем «не знает» и «частично»; из тем «не знает» вопросов вдвое больше.

## Права (RLS) — каждое правило проверяется тестом

- Учитель видит `answers` и `test_runs` ученика, только если ученик в его классе **и** `subject_id` совпадает с предметом класса.
- Учитель видит только свои классы и их состав; список учителей нигде не показывается.
- Ученик видит только свои строки; чужих учеников, их ники и результаты — нет (в том числе одноклассников).
- Учитель удаляет ученика из класса: убирается членство и все ответы и тесты ученика **по предмету этого класса**.
  Результаты по другим предметам остаются для других учителей. Если ученик больше ни в одном классе — аккаунт удаляется целиком.

## Решено владельцем

1. Уровень — по последним 20 ответам на тему, число в настройках (№62).
2. Класс = один предмет. Кнопка «Создать класс по другому предмету с теми же учениками»: новый код, ученики добавлены сразу (№63).
3. Тесты по тому же предмету из других классов учитываются, в отчёте пометка «тема N класса» (№64).
