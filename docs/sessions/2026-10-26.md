- **Пароль базы.** Сначала в `.env` стоял образец, потом старый пароль. К вечеру связь с базой заработала, все три новые миграции загружены.

- **Админка «слишком крупная»** и **шапка на узком телефоне** — исправлены (шрифты, ширина, значок вместо кнопки).
- **Адрес bilimtest.vercel.app занят** чужим сайтом — Vercel дал адрес bilimtest-chi.vercel.app.
- **Владелец забыл пароль админки** — в админке сделано «Забыли пароль?» (письмо со ссылкой → новый пароль), владелец вошёл.
- **В бесплатном Supabase нет резервных копий** — сделаны свои команды `npm run backup` / `restore` (на компьютере нет pg_dump).
- **Загрузку в основную базу остановила защита Claude Code** — владелец разрешил явно («загружай без тестового»).
- **11 класс не загружался:** Supabase оборвал соединение, зависшая транзакция держала блокировку. Закрыли её, загрузка прошла.

- **В таблицах переноса темы названы сокращённо** («ФСУ», «ОВР») — скрипт находит их сам и показывает, что нашёл; 7 названий старых тем в таблицах уточнены.
