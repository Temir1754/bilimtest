# Принятые решения

Решения здесь не пересматриваются без согласия владельца проекта. Новые решения — в конец файла.

| # | Дата | Решение | Причина |
|---|---|---|---|
| 1 | 2026-10-21 | Стек: Vite + React + TypeScript, Supabase (Postgres, Auth, RLS, Storage), деплой на Vercel, формулы KaTeX | Задано владельцем; бесплатные тарифы, без своего сервера |
| 2 | 2026-10-21 | Дизайн переносится из старого template.html без изменений | Задано владельцем; дизайн уже нравится и проверен на телефонах |
| 3 | 2026-10-21 | Темы может создавать учитель; предметы и любое удаление — только админ | Учителям нужно быстро добавлять темы; удаление и структура предметов — риск потерять данные |
| 4 | 2026-10-21 | Учитель не может менять опубликованные вопросы и пишет жалобу. «Предложить правку» (копия-черновик → одобрение админом) — отдельным шагом в конце этапа 6 | Сначала простая и безопасная модель прав, удобство — потом |
| 5 | 2026-10-21 | Тесты RLS запускаются на отдельном бесплатном проекте Supabase | Не трогать настоящие данные; локальной базе нужен Docker, это сложнее |
| 6 | 2026-10-21 | В README — как разбудить бесплатный проект Supabase, уснувший после недели без активности | Бесплатный тариф ставит неактивные проекты на паузу |
| 7 | 2026-10-21 | Защита от спама: ограничение частоты + скрытое поле-ловушка, без капчи | Капча мешает детям на слабых телефонах |
| 8 | 2026-10-21 | questions.legacy_key — ключ вида `math\|5\|0\|3` для идемпотентного импорта; для тем — «предмет\|класс\|номер» | Повторный импорт обновляет, а не дублирует |
| 9 | 2026-10-21 | questions.review_comment — комментарий админа при возврате вопроса | Учителю нужно знать, что исправить |
| 10 | 2026-10-21 | Статусы жалоб: new / fixed / rejected | Простой и понятный учёт |
| 11 | 2026-10-21 | Формулы: `\( … \)` в строке и `\[ … \]` отдельно; знак `$` не используется | В вопросах информатики есть ссылки Excel вида `$A$1` |
| 12 | 2026-10-21 | Текст, одинаковый на всех языках, при импорте копируется во все три поля | Проще база и формы; в админке есть «Скопировать из русского» |
| 13 | 2026-10-21 | Статистику и попытки анонимные ученики пишут только через функции базы, не напрямую в таблицы | Иначе любой мог бы испортить статистику |
| 14 | 2026-10-21 | Лучшие результаты ученика хранятся в его браузере с прежними ключами `bt-prefs` и `bt-best` | Без регистрации; у прежних пользователей результаты не теряются |
| 15 | 2026-10-21 | ИИ вызывается только через Supabase Edge Function; ключ API — в секретах Supabase | Ключ никогда не попадает в браузер |
| 16 | 2026-10-21 | Объяснения ИИ кэшируются (вопрос + неверный вариант + язык) в ai_explanations | Следующий ученик получает ответ мгновенно и бесплатно |
| 17 | 2026-10-21 | У учеников нет свободного чата с ИИ — только кнопка «Объясни мою ошибку» | Защита детей и бюджета |
| 18 | 2026-10-21 | Модели ИИ задаются переменными окружения: claude-haiku-5-5 для объяснений, claude-sonnet-5-5 для админки | Легко сменить модель без правки кода |
| 19 | 2026-10-21 | Ученик в классе входит анонимно (Supabase anonymous sign-in) по коду класса, имя + первая буква фамилии | Минимум личных данных детей, без email и пароля |
| 20 | 2026-10-21 | Задание имеет режим, его выбирает учитель: «Тренировка» — верно/неверно сразу после каждого вопроса; «Контрольная» — результат только после сдачи | Разные цели: закрепление и проверка знаний |
| 21 | 2026-10-21 | Лимит анонимных входов Supabase поднимаем; защита от злоупотреблений — нашими ограничениями частоты в функциях базы | В школе весь класс выходит в интернет с одного IP-адреса |
| 22 | 2026-10-21 | Лимиты «Объясни мою ошибку» по умолчанию: 10 в час с устройства, 500 в день на весь сайт | Баланс пользы и бюджета; значения меняются в настройках |
| 23 | 2026-10-21 | Объяснения для частых ошибок генерируются заранее пакетом (Batch API) и попадают на проверку в админку | Вдвое дешевле, ученик получает ответ мгновенно, текст проверен человеком |
| 24 | 2026-10-21 | У вопросов есть sort_order (порядок внутри темы) — поля не было в исходной схеме | Тест по теме показывает вопросы в заданном порядке |
| 25 | 2026-10-21 | Импорт подключается к базе напрямую и выполняется одной транзакцией; по умолчанию не трогает уже загруженное, `--force` перезаписывает | Либо всё, либо ничего; правки из админки не затираются случайно |
| 26 | 2026-10-21 | Проверка «3–4 варианта, ровно один правильный, текст на нужных языках» делается в базе только при статусе published | Черновик можно сохранять незаконченным |
| 27 | 2026-10-21 | Варианты ответа уникальны по (вопрос, номер 0–3); id варианта не меняется при повторном импорте | Не больше 4 вариантов; на id вариантов будут ссылаться объяснения ИИ (этап 9) |
| 28 | 2026-10-21 | Ограничение частоты считается по хэшу IP-адреса; сам адрес не хранится | Минимум личных данных |
| 29 | 2026-10-21 | Лимиты хранятся в таблице app_settings (по умолчанию: 600 попыток и 30 жалоб в час с одного адреса) | Админ меняет без программиста; запас для школы с общим IP |
| 30 | 2026-10-21 | У попытки есть subject_id и grade; topic_id пустой у смешанного теста. У жалобы — язык и user_id (если вошёл) | Смешанный тест не привязан к одной теме; админу нужен язык, на котором заметили ошибку |
| 31 | 2026-10-21 | Ключи Supabase называются по-новому: publishable (для браузера) и secret (только для скриптов и тестов) | Так их показывает Supabase; старые anon/service_role тоже работают |
| 32 | 2026-10-21 | Правила доступа проверяются дважды: на локальном Postgres (PGlite) в `npm test` и на тестовом проекте в `npm run test:db` | Быстрая проверка без интернета + проверка настоящего API |
| 33 | 2026-10-21 | Каждая миграция явно выдаёт права на новые таблицы (`grant`), автоматические права Supabase отозваны | Новая таблица не окажется случайно открытой для всех |
| 34 | 2026-10-26 | Этап 5 (админка) делается раньше этапа 4; проверка на тестовом проекте (`npm run test:db`) отложена | Решение владельца: сначала работать с вопросами на сайте. Правила доступа уже проверены на PGlite |
| 35 | 2026-10-26 | Админка открывается по адресу /admin без библиотеки маршрутов: main.tsx смотрит на адрес и загружает код админки отдельным файлом | Ученик не скачивает код админки; одного адреса хватает без лишней библиотеки |
| 36 | 2026-10-26 | Вопрос с вариантами сохраняется одной функцией базы `save_question` (security invoker — действуют обычные правила доступа) | Опубликованный вопрос проверяется в конце транзакции; по отдельным запросам смена правильного ответа давала бы ошибку |
| 37 | 2026-10-26 | Фильтр «язык» в админке показывает вопросы без текста на выбранном языке | Так быстрее всего найти, что ещё не переведено |
