- Старый сайт (один HTML-файл и скрипт сборки) сохранён в git и перенесён в папку `legacy/`.
- **Этап 1.** Составлен и согласован план проекта из 10 этапов, заведён журнал решений и правила работы (`CLAUDE.md`).
- **Этап 2.** Сайт для учеников переписан на Vite + React + TypeScript:

  - экраны: главная, предмет, тест, результат; смешанный тест на 10 вопросов;

- **Этап 3 (до подключения к Supabase).** Подготовлена база:

  - правила доступа: все видят только опубликованное, учитель — свои черновики, админ — всё;
  - функции для учеников: отправка результата и жалобы, защита от спама без капчи;
  - хранилище картинок вопросов;
  - скрипт переноса вопросов из `data/*.json` в базу;
  - проверки базы на локальном Postgres (PGlite) без интернета.
