# Білімтест — бесплатные школьные тесты (4–11 классы)

Сайт тестов по 16 предметам на казахском, русском и английском языках.
Сейчас: 16 предметов, 267 тем, 1336 вопросов.

Проект переводится на Vite + React + TypeScript + Supabase. Сейчас сайт берёт вопросы из папки `data/`;
после подключения Supabase они будут храниться в базе и редактироваться в админке.

## Что где лежит

| Файл / папка | Зачем |
|---|---|
| `src/site/` | Экраны для учеников: главная, предмет, тест, результат |
| `src/lib/` | Логика теста, загрузка данных, хранение результатов |
| `src/i18n/ui.ts` | Тексты интерфейса на трёх языках |
| `src/styles/app.css` | Оформление (перенесено со старого сайта) |
| `data/*.json` | Вопросы, по одному файлу на предмет |
| `tests/` | Автоматические проверки |
| `legacy/` | Старый сайт одним файлом (на память) |

## Как запустить на своём компьютере

Нужен Node.js (уже установлен). Откройте терминал в этой папке и выполните один раз:

```
npm install
```

Запуск сайта для разработки (изменения видны сразу):

```
npm run dev
```

Затем откройте в браузере адрес, который покажет команда (обычно http://localhost:5173). Остановить — `Ctrl+C`.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | Запускает автоматические проверки, включая проверку всех вопросов в `data/` |
| `npm run build` | Собирает готовый сайт в папку `dist/` |
| `npm run preview` | Показывает собранный сайт из `dist/` |

## Формат вопросов в data/*.json

**Правильный ответ всегда первым**, сайт сам перемешивает варианты:

```json
[["Вопрос на казахском", "Вопрос на русском", "Question in English"], "правильный", "неверный 1", "неверный 2", "неверный 3"]
```

- Текст, одинаковый на всех языках (числа), пишется одной строкой: `"x² − 9"`.
- Текст на трёх языках — массив из трёх строк: `["қызыл", "красный", "red"]`.
- 3 или 4 варианта ответа.
- Формулы: `\( x^2 \)` внутри строки, `\[ \frac{a}{b} \]` отдельной строкой. Знак `$` для формул не используется.
- Если в тексте вопроса есть перенос строки, всё после него показывается как блок кода.

После правок запустите `npm test`, он найдёт ошибки в файлах.
