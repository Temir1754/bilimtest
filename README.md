# Білімтест — бесплатные школьные тесты (4–11 классы)

Сайт тестов по 16 предметам на казахском, русском и английском языках.
Без регистрации и без сервера: весь сайт — один файл `index.html`.

## Что внутри

| Файл / папка | Зачем |
|---|---|
| `index.html` | Готовый сайт. Его и нужно загружать на хостинг. |
| `data/*.json` | Вопросы, по одному файлу на предмет. Здесь вы добавляете и правите тесты. |
| `template.html` | Оформление и логика сайта (без вопросов). |
| `build.py` | Проверяет вопросы и собирает `index.html` из `template.html` и `data/`. |

Сейчас: 16 предметов, 267 тем, 1336 вопросов (по 5 на тему).

## Как выложить бесплатно

**Netlify (проще всего):** зайдите на app.netlify.com/drop и перетащите папку с `index.html`. Через минуту будет адрес вида `имя.netlify.app`.

**GitHub Pages:** создайте репозиторий, загрузите `index.html`, затем Settings → Pages → Branch: `main` → Save. Адрес будет `ваш-логин.github.io/имя-репозитория`.

Подойдёт любой хостинг статических сайтов: Cloudflare Pages, Vercel, обычный хостинг. Файл можно открыть и просто двойным щелчком на компьютере — работает без интернета (кроме шрифтов).

## Как добавить вопросы

1. Откройте нужный файл в `data/`, например `data/math.json`.
2. Найдите класс (`"5"`) и тему, допишите вопрос в её список.
3. Запустите `python3 build.py` — он проверит ошибки и пересоберёт `index.html`.

Формат вопроса — **правильный ответ всегда первым**, сайт сам перемешивает варианты:

```json
[["Вопрос на казахском", "Вопрос на русском", "Question in English"], "правильный", "неверный 1", "неверный 2", "неверный 3"]
```

- Текст, одинаковый на всех языках (числа, формулы), пишется одной строкой: `"x² − 9"`.
- Текст на трёх языках — массив из трёх строк: `["қызыл", "красный", "red"]`.
- Можно 3 или 4 варианта ответа.

Новая тема:

```json
[["Тақырып атауы", "Название темы", "Topic name"], [ ...вопросы... ]]
```

Новый предмет: скопируйте любой файл из `data/`, поменяйте `id` (он должен совпадать с именем файла), `icon`, `name`. Поле `"lang": "kk"` ставится, если вопросы есть только на одном языке (как у языковых предметов).

## Что можно сделать дальше

- Больше вопросов на тему (10–20), чтобы тесты не повторялись.
- Пояснение к правильному ответу.
- Учительский режим: общий результат класса (потребуется сервер или Google Forms/Sheets).
- Подготовка к ЕНТ: длинные тесты с таймером.
